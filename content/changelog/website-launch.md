# 🌐 A home for Code

Code gained a public website with focused guides for getting started,
working with agents, hosting, operating a cluster, and following changes.

## What changed

The site complements the repository documentation with a smaller starting
point for people evaluating or operating Code. The in-repository technical
reference remains the authoritative place for detailed design material.

## Why

Git infrastructure needs both an approachable front door and precise operating
documentation. The site provides the first; the repository remains where
implementation-level promises are recorded.
